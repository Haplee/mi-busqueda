# 9. Recursos

Recursos públicos, no recommendations de curso. Esta carpeta es pequeña a
propósito: una lista de veinte recursos es una lista que no se usa.

## Cómo buscar ofertas

Esto lo haces tú, en tu navegador, con alertas. Nada de esto se automatiza desde
aquí.

| Portal | Para qué | Nota |
|--------|----------|------|
| [LinkedIn](https://www.linkedin.com/jobs) | El mayor volumen | Límite de búsquedas gratuitas. Filtra bien, no filtres de más |
| [InfoJobs](https://www.infojobs.net) | España, muchos sectores | Filtros de salario útiles |
| [Tecnoempleo](https://www.tecnoempleo.com) | Perfiles técnicos | Bastante técnico |
| [Indeed](https://www.indeed.es) | Volumes grandes | Mucho ruido, muchos falsos positivos |
| [Glassdoor](https://www.glassdoor.es) | Salarios reales | El bloque de empresas es útil |
| Portales de empleo público | Hetero | Depende de tu país |

Configura alertas con `4-ofertas/alertas.md`. La regla es simple: una alerta por
término, y se borra la que no sirve para nada en dos meses.

## Para saber cuánto paga

| Fuente | Para qué |
|--------|----------|
| Glassdoor, Indeed, Levels.fyi | Rangos por puesto y ciudad |
| Convenios collectors públicos | El suelo de tu sector |
|_tu propia negociación | El único número fiable |

Antes de una entrevista, ten un número en la cabeza y una razón para él.

## Para escribir mejor

| Recurso | Nota |
|---------|------|
| [HackerRank Skills Certification](https://www.hackerrank.com/skills-directory) | Gratis, verificable, tiene valor real |
| [Exercism](https://exercism.org) | Práctica con mentoría community |
| [Refactoring Guru](https://refactoring.guru/es) | Patrones de diseño, en español |
| [MDN](https://developer.mozilla.org/es/) | Referencia web, la que más se consulta |
| [roadmap.sh](https://roadmap.sh/es) | Rutas de aprendizaje por rol |

Cuidado con los cursos de pago sin fecha de caducidad. La tecnología cambia; el
curso, no siempre.

## Para la parte de CV y entrevistas

| Recurso | Nota |
|---------|------|
| Correctores ortográficos | Úsalos si tienes dudas. No para reescribir tu forma de escribir: se nota |
| Manuales de tu sector | Los que publica tu cámara sectorial o tu asociación profesional |
| [MIT Missing Semester](https://missing.csail.mit.edu/) | Si te dedicas a sistemas. De cabeza, pero merece la pena |

## Cómo añadir un recurso aquí

Solo si lo has usado. Dos líneas de por qué. Si no lo has usado, no aporta nada
y solo ocupa espacio.
