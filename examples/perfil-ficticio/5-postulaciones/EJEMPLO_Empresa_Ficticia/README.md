# Ejemplo: postulación a Empresa Ficticia

PERSONA FICTICIA. Todo este contenido es inventado.

## Qué hay aquí

| Fichero | Qué muestra |
|---------|-------------|
| `oferta.md` | Una oferta copiada y llena, con el encaje razonado |
| `carta.md` | Una carta real con notas sobre por qué está escrita así |
| `notas.md` | El seguimiento: por qué se eligió, qué se envió, qué pasó |

## El recorrido

1. `4-ofertas/plantilla-oferta.md` → esta `oferta.md`, rellena.
2. `2-documentos/plantillas/carta-presentacion.md` → esta `carta.md`.
3. El pipeline de `4-ofertas/` tiene una fila con este ID.
4. `notas.md` recoge lo que pasó después.

## Lo que hay que mirar

**En la oferta:** la tabla de encaje. Siete u ocho de media, y aun así se
envía. La tabla no decide, informa.

**En la carta:** la sección "Notas sobre esta carta", que explica cada decisión.
Una plantilla sin explicar por qué está escrita así es una plantilla que se
copia mal.

**En las notas:** la sección "Qué haría distinto". Es la más útil de las tres,
porque es la única que cambia algo.
