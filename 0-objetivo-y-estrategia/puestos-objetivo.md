# Puestos objetivo

Un puesto objetivo no es un título: es una combinación de **rol + sector + tipo de
empresa**. Si solo defines el título, acabarás aplicando a 300 ofertas que no encajan.

## Cómo usarlo

Para cada puesto objetivo rellena las tres partes. Si no rellenas la columna "por qué",
ese puesto no debería estar en la lista.

---

## Cómo saber si un puesto objetivo funciona

Después de 20 candidaturas, mira las métricas por tipo de puesto
(`4-ofertas/scripts/ver-metricas.py`):

| Puesto objetivo | Candidaturas | Respuestas | Entrevistas | Veredicto |
|-----------------|--------------|------------|-------------|-----------|
| [PUESTO_1] | | | | Mantener / Ajustar / Soltar |
| [PUESTO_2] | | | | Mantener / Ajustar / Soltar |

Regla práctica:

- **0 respuestas en 15+ candidaturas** → tu perfil no encaja con ese puesto. No es un
  problema de CV: es un problema de objetivo. Suelta o reposiciona.
- **Respuestas pero 0 entrevistas** → el problema es el CV o la carta, no el puesto.
- **Entrevistas pero nada más** → el problema es el encaje en la fase final.

## Matices de búsqueda

Los títulos de puesto varían mucho entre sectores. Antes de decidir tus sinónimos,
mira cómo se llaman las cosas en las ofertas que ya has guardado en `5-postulaciones/`.
Es mejor usar el vocabulario real del mercado que el que te suena lógico.
